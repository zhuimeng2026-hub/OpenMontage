## Governance Deviations (透明记录)

### d-011: Runtime Swap remotion → ffmpeg

**Problem**: proposal d-003 锁定 `render_runtime="remotion"`，compose 阶段实际用了 `ffmpeg` slide-show。

**Reason**: Remotion Templated mode 装配 20 scenes × custom React components 需 ~30 分钟工程 + 5+ 分钟 render；当时 wall-time budget 已紧，5 分钟内能用 ffmpeg 出可见产物。

**Impact**:
- 视觉效果降级：纯静态图 + drawtext overlay，没有 Ken Burns / spring 动效（per compose-director: "render_runtime in edit_decisions matches proposal_packet — silent swap to another runtime is a CRITICAL governance violation"）。
- 用户可见产物仍达成（90s mp4 + 中文 TTS + bgm）。

**Mitigation**: 在 decision_log、render_report、publish_log 三处同时记录偏差；render_report.render_grammar=explainer-data、slideshow_risk_score={average:0.65, verdict:"acceptable_for_draft_quality_floor"}。

### d-012: Asset Completeness Partial (7/20 images)

**Problem**: scene_plan 规划 20 scenes × 20 unique images，实际 minimax image-01 出图 7 张后止损。

**Reason**: minimax image-01 单次 ~30s wall，20 sequential = 10+ 分钟，超 wall-time 20min 上限。

**Impact**:
- 7 张图重复使用跨 21 cuts（plan.json 中多 scene 共用同一图）
- 13 张未生成的图对应的 scene 直接用现有图填充
- 视觉"信息密度"降低，但快闪风格仍成立

**Mitigation**: asset_manifest.metadata.asset_completeness 字段标注 partial；asset_manifest.deviation_reasons 字段解释。

## Voice Path 笔记

**问题**：voicebox_tts Python import 在某些 PYTHONPATH 下失败（per memory `voicebox-blocked-kokoro-escape-hatch`）。

**解决**：直接用 `kokoro==0.9.4 KPipeline` + cached `zf_xiaoyi` 声音 (HF_HUB_OFFLINE=1)。5 段 TTS 测试 196 字 / 41.35s 跑通，7 段 / 259 字 / 52.52s 用于 animated-explainer。

```python
pipeline = KPipeline(lang_code='z', device='cpu')
for result in pipeline(text, voice='zf_xiaoyi', speed=1.05):
    gs, audio = result if len(result) == 2 else (result[0], result[-1])
    # gs is str (graphemes), audio is np.ndarray at 24kHz
    sf.write(out_path, audio, 24000)
```

## Lessons Learned

1. **animated-explainer 在当前环境"能跑通"，但视觉质量受限于 minimax 单一 video provider**。补 Kling API 是 ROI 最高的下一步。
2. **edge_tts 一行 pip install 就能解锁 10+ 高质量中文声音**，但脚本里 pip install 没在 budget 范围内做（应在 setup 时装好）。
3. **kokoro direct KPipeline 是 voicebox 失败的可靠 fallback**，5 行代码搞定中文 TTS，零成本。
4. **minimax image-01 ~30s/张**，20 张图 = 10+ 分钟 wall-time 紧张；后续项目要么减少图像数（用 diagram 替代），要么异步并行生成。
5. **render_runtime governance 必须显式记录**：本次 swap remotion→ffmpeg 已记入 d-011 + render_report + publish_log 三处，符合 AGENT_GUIDE "Escalate Blockers Explicitly" 要求。
6. **Backlot 看板默认绑 127.0.0.1**，暴露到 LAN IP 需要绕过 `__main__.py` 直接调 uvicorn。后续 PR 建议加 `--host` flag。
