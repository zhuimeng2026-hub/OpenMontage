# Qwen3-TTS 收费说明

**结论：Qwen3-TTS 是收费服务（非免费）。**

## 收费模式

DashScope 上的 Qwen3-TTS 采用按量计费（pay-as-you-go）：

| 模型 | 价格 |
|------|------|
| `qwen3-tts-flash` | **$0.000015 / 字符** |

这个价格非常低 — 生成一段 1000 字的中文语音仅需约 **$0.015**（约人民币 0.1 元）。

## 费用承担方

当前部署中：
- DashScope API Key 已配置在 `.env` 中（`DASHSCOPE_KEY=sk-847cc...`）
- 费用由该 API Key 关联的阿里云账户支付
- Voicebox 的语音克隆功能底层调用 Qwen3-TTS，每次克隆/合成都会产生 API 调用费用

## 总结

Qwen3-TTS **不是免费服务**，但费用极低，属于"几乎可以忽略不计"的按量计费模式。如果用量很小，费用几乎不可感知。
