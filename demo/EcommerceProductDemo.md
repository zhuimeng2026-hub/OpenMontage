# Remotion 电商产品演示模板

入口脚本：`src/EcommerceProductDemo.tsx`

这是一个约 25 秒的完整电商产品演示流程，适合商品详情页、信息流广告、品牌官网和短视频广告。默认示例沿用了现有的行李箱图片，但脚本通过 props 将商品文案、价格、规格和图片槽位参数化。

## 流程结构

| 时间 | 场景 | 目的 | 需要的图片 |
|---|---|---|---|
| 0–3 秒 | Hook / 品牌开场 | 第一眼说明品牌、产品和核心承诺 | `hero`：生活方式主视觉 |
| 3–7 秒 | 产品全貌 | 让观众看清产品是什么、适合谁 | `product`：产品三分之四角主图 |
| 7–10.5 秒 | 卖点一 | 解释最有感知的功能 | `product` 或对应功能图 |
| 10.5–14 秒 | 卖点二 | 展示材质、结构或性能 | `detail`：细节特写 |
| 14–17.5 秒 | 卖点三 | 展示使用体验或内部设计 | `lifestyle`：使用场景或结构图 |
| 17.5–21.5 秒 | 规格与信任 | 给出容量、重量、保修等购买依据 | `lifestyle` 或产品细节图 |
| 21.5–25 秒 | 价格与 CTA | 明确价格、优惠、配送和行动入口 | 可复用 `product`，也可提供结束板图 |

## 必备图片清单

### 1. `hero`：生活方式主视觉

- 产品正在真实使用中的场景，不要只是白底抠图。
- 画面要能表达产品的使用环境，例如机场、客厅、办公室、户外、厨房或健身房。
- 主体应有明显的留白区域，方便叠加品牌名和核心卖点。
- 建议提供 16:9 横图，至少 2560×1440；如果要做短视频，再额外提供 9:16 竖图，至少 1440×2560。
- 画面不要放关键文字，文字由 Remotion 统一叠加，避免裁切和品牌字体不一致。

### 2. `product`：产品三分之四角主图

- 能同时看到产品正面和侧面，最适合作为产品全貌和英雄镜头。
- 产品边缘要清楚，背景尽量干净，避免手、人物或其他物体遮挡。
- 推荐 PNG 透明背景；如果是 JPG，背景应为浅色且均匀。
- 建议提供 2000×2000 以上的正方形或接近正方形图片。
- 产品在画面中应占 60%–80%，四周留出安全边距，便于缩放和动画。

### 3. `detail`：功能或材质特写

- 只拍一个卖点：按钮、接口、轮子、拉链、面料纹理、屏幕、收纳结构等。
- 需要足够近，让观众能在 2–3 秒内看懂细节。
- 最好准备 2–3 张不同角度的细节图，脚本可以在后续版本中轮播使用。
- 建议 1600×1200 以上，横向或 4:3 构图优先。

### 4. `lifestyle`：使用体验或结构图

- 用于证明“产品如何融入生活”，可以是人物使用图、打开后的内部结构图、收纳前后对比图或环境中的产品图。
- 人物可以出现，但不要让人物成为画面主角；产品仍要清晰可辨。
- 如果产品卖点是容量、尺寸或防护，优先提供带参照物的图片。
- 建议至少 2000×1400，主体不要贴边。

## 可选图片

- `logo`：透明背景 SVG/PNG。当前模板直接显示文字品牌名，因此不是必需项。
- `ending`：专用结束板或二维码图。如果没有，模板会使用文字 CTA；真实投放时建议提供可扫码的正式二维码。
- `feature_02`、`feature_03`：如果三个卖点差异很大，建议每个卖点各准备一张专属图片，而不是重复使用主图。

## 图片命名建议

```text
public/product/
├── hero.jpg
├── product-main.png
├── detail-feature-01.jpg
├── lifestyle-use.jpg
├── logo.svg
└── qr-code.png
```

然后把这些路径传给 `assets`：

```ts
assets: {
  hero: "product/hero.jpg",
  product: "product/product-main.png",
  detail: "product/detail-feature-01.jpg",
  lifestyle: "product/lifestyle-use.jpg",
  music: "bgm.wav",
}
```

## 文案需要准备什么

- 品牌名、产品名
- 一句话核心承诺（不要超过 12 个词）
- 三个卖点：每个卖点一个短标题和一句解释
- 3–5 个关键规格，例如尺寸、重量、容量、续航、材质、保修
- 售价、划线原价、优惠信息
- 配送、退换货或保修承诺
- 最终 CTA，例如“立即购买”“加入购物车”“了解更多”

## 注意事项

- 所有图片应由同一套光线、色彩和产品外观组成，避免不同拍摄批次造成跳切。
- 不要给脚本提供带水印、带平台 UI 或带旧价格的图片。
- 产品主图应与最终售卖版本一致，尤其是颜色、尺寸、配件和包装。
- 真实投放前，把模板中的示例价格、规格、优惠和二维码全部替换成经过审核的正式内容。
